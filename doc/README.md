# doc

このディレクトリは、手書き文書・整理メモ・結果の置き場です。

## 置き方

- `fig/`: 手書き figure source と代表図
- `finalanalysis/`: 最終解析のメモ・結果・要約
- `mainexp/`: 実験条件や run 固有のメモ
- `mock/`: mockdata 関連のメモ
- `test/`: 手動確認で出た図の置き場
- `theory/`: 理論メモ

## 今後のルール

- `.tex`, `.md`, 要約 `.txt` は残す
- `.aux`, `.dvi`, `.log` は生成物なので残さない
- 大量の scan 出力を残す場合は、何の条件かが README なしでも分かる命名にする
- 「卒論のためだけに作った図」と「今後も参照する基準図」は分けて管理する
